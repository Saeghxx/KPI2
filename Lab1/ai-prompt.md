# Задача для ШІ

Модель `er/er.mmd` згенеровано ШІ за цим промтом. Якщо промт змінювався після аудиту, нова версія додається нижче з датою, а стара лишається.

## Версія 1

**Роль:** ти — аналітик даних, що будує концептуальну ER-модель.

**Вхід:** файл `spec.md` (сутності, атрибути, зв'язки, бізнес-правила, критерії AC-1…AC-10).

**Завдання:** побудуй ER-модель онлайн-магазину книг у синтаксисі Mermaid `erDiagram` суворо за `spec.md`.

**Обмеження (дублюють критерії прийняття):**
- Використовуй лише сутності, атрибути та зв'язки зі `spec.md`; нічого не вигадуй і не пропускай.
- Назви полів — символ у символ як у spec.
- Усі `*_id` мають тип `int`.
- Познач `PK` і `FK`; для складених ключів — `PK, FK` на кожному полі ключа.
- Кардинальності — за таблицею розділу 3 spec.
- Чисті M:N (BOOK–AUTHOR, BOOK–CATEGORY) — прямим зв'язком `}o--o{`, без сполучних сутностей.
- Асоціативні сутності лише ORDER_ITEM і REVIEW.
- Жодного SQL DDL, ORM, індексів чи типів конкретної СУБД.

**Вихід:** лише вміст файла `er/er.mmd`, без пояснень.
